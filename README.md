# 쇼핑쇼츠 콘텐츠 허브 (Notion)

기획(대본)과 편집(업로드)이 같이 쓰는 노션 워크스페이스 구조 기록.

- 허브 페이지: https://app.notion.com/p/3f17ef0e649f8114a1cddef49ba9492c

## 구조
- **📦 제품** DB: 제품명, 선정일, 상품 링크, 소구 포인트, 촬영 소스, 공통 메모, 제품 상태
- **🎬 콘텐츠** DB: 제품 1개당 6줄 (채널 소이홈/꿀템담아/홈앤살림 × 플랫폼 인스타/유튜브)
  - 대본, 캡션, 해시태그, 상태, 피드백, 업로드 예정일, 업로드 링크, 완성 영상

## 상태 흐름
① 대본작성중 → ② 편집요청 → ③ 편집중 → ④ 확인요청 → (🔁 수정요청) → ⑤ 업로드완료
